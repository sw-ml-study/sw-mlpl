User report: serious caching -- Usage Guide changes invisible across many reloads. Root cause: mlpl-serve's static handler sends no Cache-Control headers, so browsers cache index.html which points at the old hashed wasm bundle. Fix: no-cache (must-revalidate) for *.html, long-lived immutable for hashed assets (*.wasm/*.js with hash in name). TDD via a serve test asserting the headers. Rebuild + restart local server.
