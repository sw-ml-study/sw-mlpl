Added print(v) and eprint(v) builtins via eval-side dispatch. Both write the value's Display form to stdout / stderr followed by a newline and return v unchanged so calls compose into expressions ('x = print(some_computation)' both binds and shows). 5/5 new tests pin the composability contract; stream routing verified by running mlpl-repl -f against a small script with stdout/stderr separation. New 'Scripting' section in docs/lang-reference.md; new 'print / eprint (builtins)' glossary entry (count 278 -> 279).
