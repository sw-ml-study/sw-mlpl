This recreates the playground's *CUDA LoRA fine-tune* demo as a literate
program. We pretrain a tiny language model, wrap it with LoRA adapters,
fine-tune *only the head adapters* on the NVIDIA GPU, and watch the loss
fall -- concrete learning on the device. The blocks share one
~:session cuda~, so state threads through exactly as if typed into the REPL.

* Step 1 -- prepare the corpus

A tiny fixed token corpus, turned into next-token (X -> Y) training pairs
with a context window of 4. (The demo uses explicit ids so it is fully
self-contained and fast; swap in ~train_bpe~ on real text for a serious
run.)

#+begin_src mlpl
ids   = [1, 3, 5, 7, 2, 4, 6, 0, 9, 11, 13, 15, 2, 4, 6, 0, 1, 3, 5, 7, 2, 4, 6, 0]
X_all = shift_pairs_x(ids, 4)
Y_all = shift_pairs_y(ids, 4)
X     = reshape(X_all, [reduce_mul(shape(X_all))])
Y     = reshape(Y_all, [reduce_mul(shape(Y_all))])
shape(X)
#+end_src

* Step 2 -- define and pretrain a tiny language model

A minimal decoder -- embedding, one causal-attention block, a final RMS
norm, and a linear head -- pretrained for 20 Adam steps on the CPU so it
has some structure to specialize from. This is the *head-only-LoRA demo
architecture*: ~lora()~ adapts only the head ~Linear~ (the attention
projections live in the ~Attention~ layer and stay frozen), so the whole
fine-tune step is a single graph differentiable w.r.t. the head adapters.

#+begin_src mlpl
V = 16 ; d = 8 ; h = 1
base = chain(embed(V, d, 0), residual(chain(rms_norm(d), causal_attention(d, h, 1))), rms_norm(d), linear(d, V, 2))
experiment "cuda_base" { train 20 { adam(cross_entropy(apply(base, X), Y), base, 0.01, 0.9, 0.999, 0.00000001); loss_metric = cross_entropy(apply(base, X), Y) } }
last_losses
#+end_src

* Step 3 -- wrap with LoRA (freeze the base)

~lora(base, 2, 4.0, 7)~ freezes every base weight and adds a rank-2
adapter pair on the head. Only those adapters train from here.

#+begin_src mlpl
student = lora(base, 2, 4.0, 7)

* Step 4 -- fine-tune the adapters on the GPU

~to_device(student, "cuda")~ + ~to_device(X, "cuda")~ stamp the CUDA
placement; inside ~device("cuda")~, ~apply~ + ~cross_entropy~ + the Adam
update all run on the GPU through candle. Watch the loss fall.

#+begin_src mlpl
device("cuda") {
  to_device(student, "cuda")
  to_device(X, "cuda")
  experiment "cuda_lora" {
    train 30 {
      adam(cross_entropy(apply(student, X), Y), student, 0.05, 0.9, 0.999, 0.00000001);
      loss_metric = cross_entropy(apply(student, X), Y)
    }
  }
}
last_losses
#+end_src
